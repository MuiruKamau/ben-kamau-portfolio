# Ben Kamau — Portfolio

Personal portfolio of Benson (Ben) Kamau, a backend-first software engineer in Nairobi building financial infrastructure, identity platforms and AI agents.

Built with Next.js (App Router), React and TypeScript. Case studies are statically generated from [`lib/content.ts`](lib/content.ts).

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Structure

- `app/page.tsx` — landing page
- `app/work/[slug]/page.tsx` — case study pages
- `lib/content.ts` — all case study and profile content
- `components/` — section links that scroll without hashes in the URL
